# Residual review findings — 7a73e97 (issue #28)

`feat(seed): backfill interest_search_query for the 120 v2 sub-niche nodes`

Two-agent adversarial panel (correctness/logic + simplicity/reuse + data-integrity).
**No must-fix.** Correctness and data-integrity verdicts were clean (UPDATE scope,
parameterization, transaction boundary, idempotency, slug re-derivation, and the
"≥1 term for both ingestion paths" guarantee all verified against the real 120-label
catalog). The items below are advisory-only, deferred here rather than churn
already-prod-verified code.

## A1 — Collapse `BackfillPlan` → `list[dict]` (simplicity, low)
`backfill_interest_query.py` `BackfillPlan` is a one-field wrapper (`self.rows`) with
no methods; every consumer immediately unwraps `.rows`, and the only real logic (the
duplicate-slug guard) lives in the free function `rows_to_plan`. Collapsing it —
return `list[dict[str, str]]`, rename the guard to `validate_unique_slugs`, drop the
~15 `.rows` indirections — removes a class + constructor with no behavior change.
Deferred (advisory; kept the class to mirror `seed_v2.py`'s flat model style).

## A2 — Trim `_DESCRIPTOR_FILLER` (simplicity, low)
The 17-word `_DESCRIPTOR_FILLER` frozenset feeds only `is_generic_label` and barely
fires on the real catalog (only `AI news & analysis` classifies generic, and it is
not even prepended because its root term is already present). It is a cheap, harmless
constant — `build_backfill_plan` fails loud if any derived query is empty for either
ingestion path, so a mis-classification cannot silently write garbage. Could be
trimmed to words demonstrably present in v2 labels; not worth a change now.

## A3 — 2-char root (`AI`) root-qualification is a no-op on the BigQuery path (latent, not reachable)
Root-prepend adds zero `match_terms` tokens for the 2-char root `AI` (the ≥3-char
filter drops `ai`). Not reachable today: no all-stopword generic label exists under
`AI`. If one were ever added, `build_backfill_plan` would **raise** (fail-loud) rather
than write a skippable query — correct defensive behavior. Worth a code comment only
if the catalog grows an all-filler `AI` sub-niche.

## A4 — Cross-module private imports (note, intended)
The script imports `_QUERY_STOPWORDS` / `_GENERIC_BROAD` (`gdelt_bigquery.py`) and
`_connect` (`seed_via_pooler.py`). This is the intended reuse (Rule 8/11) but couples
the script to three modules' private surfaces; a rename would break silently until
run. Acceptable for a one-shot seed script — flagged as a conscious choice.
